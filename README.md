# Energy Usage Analyzer

## Overview

A Python-based command-line project that analyses household appliance energy consumption and provides basic insights and recommendations.

## Features

- Collects appliance usage data
- Calculates weekly energy consumption for each appliance
- Calculates total household energy consumption
- Identifies the highest and lowest energy consuming appliances
- Analyses energy usage and provides a basic recommendation

## Technologies

- Python

## Current Version

### Version 1 — Python Fundamentals

This version was built using Python fundamentals including variables, dictionaries, loops, conditional statements, functions and calculations.

Current limitation: The program currently assumes users enter valid numerical values.
